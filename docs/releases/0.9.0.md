# Agent F-Row 0.9.0

Saved agents keep their launch-folder identity as they work in subfolders,
can reserve a lane before starting, and show their active subagents in the
Running lights.

- **Stable project matching.** Launch and current folders are tracked
  separately. Launch metadata is recovered from agent status/transcripts and
  remembered across app restarts; child activity cannot rename the parent.
- **Children stay with their parent.** Nested subagents contribute to the
  root session's roster. Child completion and late events do not create new
  foreground lanes or replace the parent's terminal identity.
- **Reserve a saved agent's lane.** Add to lane creates an Idle reservation;
  the matching agent takes it over when started. Reservations survive app
  restarts and return to Idle when the agent ends. Release frees the slot.
- **Any lane is back.** Saved agents can have no preferred lane. Their
  buttons and dropdowns occupy two rows aligned to the card's right edge.
  A short introductory paragraph explains focusing and answering agents.
- **Running lights show the agent count.** The main agent plus active
  subagents form a moving group, capped at the physical key count. Four keys
  start as `Oooo`, `OOoo`, `OOOo`, or `OOOO`, moving through the existing
  extra off-lane position. The F-row, numpad top row, Stream Deck and mini
  view share this behavior. Waiting and the numpad's M keys are unchanged.
- **Terminal matching and diagnostics.** Focus retains the parent session's
  identity, discovers and remembers live terminal tabs, and verifies the
  selected tab before sending an answer. Bounded local diagnostics record
  lane ownership and focus outcomes.
- **One Windows build workflow.** The WSL checkout remains the source;
  Windows Cargo writes to a separate output folder. The build script tests,
  installs, restarts and verifies the installed copy, with rollback on
  failure. Packaging preserves existing versioned archives and includes
  build metadata and a SHA256 checksum.

The user verified launch-folder matching and a live count rising from one
to four agents and returning to one. The compact saved-agent layout was
visually checked in the installed Windows app. The Windows workspace has
325 passing tests; build workflow checks cover packaging and rollback.
Terminal matching still has cases requiring live verification; see
[Known issues](../../KNOWN_ISSUES.md).

## Upgrade

Unzip `agent-frow-0.9.0-win64.zip` and run `agent-frow.exe` once.

Upgrading from 0.8.2 preserves saved agents and settings and needs no new
keymap import or hook registration changes. Live sessions reappear on their
next event. For upgrades from 0.8.0 or earlier, follow the V0 keymap and Codex
Interrupt setup notes in [0.8.1](0.8.1.md#upgrade); the same keymap is included
in this zip.
