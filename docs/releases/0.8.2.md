# Agent F-Row 0.8.2

Codex automatic approvals now keep the lane Running while review and execution
proceed. Previously, a permission request could leave the lane Waiting until a
long command finished, even when the automatic reviewer handled it.

- **Automatic approvals stay Running.** The app reads the effective reviewer
  from the current Codex CLI session and turn. Shell and file-edit requests
  handled by `auto_review` no longer set Waiting.
- **Actual requests still need your attention.** Questions, plan confirmation,
  and manual approvals retain Waiting. An automatic approval also preserves a
  separate pending prompt and its note.
- **Long sessions and reviewer changes are supported.** The reader finds
  settings outside the recent transcript tail and follows subsequent changes.
  Unknown settings and other request types retain the existing behavior.

Verified by the user with Codex CLI in WSL: automatic approvals remain Running,
and actual user requests still set Waiting. The Windows workspace's 301 tests
cover the state changes, transcript handling, and existing integrations.

## Upgrade

Unzip `agent-frow-0.8.2-win64.zip` and run `agent-frow.exe` once.

Upgrading from 0.8.1 requires no new keymap import or hook registration changes.
If upgrading from 0.8.0 or earlier, follow the V0 keymap and Codex Interrupt
setup notes in [0.8.1](https://github.com/timeToy34/agent-frow/blob/v0.8.1/docs/releases/0.8.1.md#upgrade);
the same keymap is included in this zip.

Codex can still delay clearing Waiting after a manual response until it reports
further activity. That separate hook limitation remains tracked in
[KNOWN_ISSUES.md](https://github.com/timeToy34/agent-frow/blob/v0.8.2/KNOWN_ISSUES.md).
